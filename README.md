# 🚀 Akash Pandey — Software Engineer Portfolio

A modern, highly responsive, and feature-packed personal portfolio website built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**. Designed with dark-mode glassmorphic aesthetic, 3D interactive tilt profile cards, smooth scroll navigation, and recruiter-friendly resume download functionality.

![Portfolio Preview](public/akash_profile.jpg)

---

## ✨ Features

- **⚡ Interactive 3D Avatar Profile**: Real-time mouse parallax tilt card built with Framer Motion.
- **💼 Full-Stack Experience & Projects**: Showcases Cyber Threat Intelligence (CTI) platforms, D3.js graph visualizations, GraphQL workflows, and full-stack applications.
- **📄 Resume Download Integration**: Direct link to download Akash's latest official resume (`Akash_Pandey_Resume.pdf`).
- **🎨 Glassmorphic Dark Design**: Modern glowing cyan-indigo gradient accents, glass panel effects, and smooth micro-animations.
- **📱 Fully Responsive**: Flawless experience across desktop, tablet, and mobile screens with custom drawer navigation.
- **🔗 Social & Coding Profiles**: Quick links to GitHub, LinkedIn, LeetCode, CodeChef, and GeeksforGeeks.

---

## 🛠️ Tech Stack & Dependencies

- **Core**: [React 19](https://react.dev/), [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/), Glassmorphism, Custom Animations
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18+) and **npm** installed on your system.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akashpandey25/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173` to view the app in real-time.

---

## 📦 Production Build

To build the application for production deployment:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
